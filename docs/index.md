# Documentation

Technical docs for the SWN Sector Generator project. See the main
[README](../README.md) for project setup and a general overview.

Each doc below covers one specific area of the project. When adding a new
doc, add a link and a short description of it here too.

## Available docs

- **[Testing](testing.md)** — how the test suite is structured, the
  conventions it follows, and how to extend it to a new data table.
- **[Data Tables and Models](data-tables.md)** — the YAML/JSON
  Schema/TypedDict architecture behind the project's game data, why all
  three exist, and how to add a new table.
